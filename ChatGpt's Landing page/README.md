# FreshCut Barbers — Local Business Landing Page

A simple single-page local business landing page built with HTML, CSS and plain JavaScript.

## Sections
- Hero
- Our Services
- How We Work
- Recent Work
- Contact Us
- Footer

## JavaScript interaction
The contact form validates the required fields and displays a demo confirmation. The Recent Work button also reveals a small note.
